## 📖 项目简介 | Introduction

**AICharacterChat** 是一个面向用户的 AI 角色对话平台，计划支持与内置或自定义 AI 角色进行带有上下文记忆的对话。

**AICharacterChat** is a user-facing AI character chat platform where users can converse with built-in or custom AI characters with contextual memory.

> 项目当前处于规划阶段，技术栈与具体功能待定。
