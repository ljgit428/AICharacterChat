## [已确认，待排期] 角色回复长度控制：有时需要长回复，有时需要短回复

- **记录日期**：2026-08-27
- **来源**：GUI 实测（天童爱丽丝会话）——角色长回复（如推荐游戏清单）常整段输出，
  用户反映"有时候需要说那么长，有时候又不需要那么长"。
- **现状**：系统提示词构建（`chat/soul.py` 的 `build_character_system_prompt_preview`
  与 prompt 组装）中**没有**任何回复长度控制，回复长度完全由模型自由发挥。
- **期望行为**：
  - 角色级"回复风格"偏好（话痨 / 标准 / 简洁），注入系统提示词，让说话量符合人设；
  - 消息级快捷控制（输入框上方"简短 · 标准 · 详细"芯片），只对当轮生效，可覆盖角色默认；
  - 软引导自动适配：回复长度与用户消息大致相当（用户简短则简短）。
- **建议方案**：
  1. 角色表单新增"回复风格"下拉，存角色字段（或注入 `response_guidelines` 头部），
     `build_character_setup_markdown` 按设置注入一条准则；
  2. 请求参数带 `length_mode`（short/standard/detailed），在当轮 prompt 尾部覆盖注入；
  3. 前端：角色表单下拉 + 聊天输入框上方三个芯片（复用"实时"按钮的样式）。
- **明确不做**：事后的"太长/太短"反馈按钮（模型无法优雅重说，体验差成本高）。
