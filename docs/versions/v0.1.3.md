# Version 0.1.3 - Realtime Voice Chat, Local TTS & Chat UX Overhaul

## Release Date
August 2026

## Overview
Version 0.1.3 introduces a realtime voice chat mode with hands-free voice interaction, local TTS voice replies powered by Genie-TTS, and a major round of chat UX improvements. The voice stack runs entirely on CPU (with optional GPU acceleration for TTS) and is decoupled from the Django process as standalone HTTP services. On the chat side, message bubbles are now paragraph-split with per-segment speak/download, session history is cached for instant character switching, and TTS playback reliability is hardened. The soul/memory panel is reworked into a searchable tree with folder-grouped uploads, and the directory layout is normalized per `docs/project-structure.md`.

Roughly 64 files changed with ~8,690 insertions across backend (Django) and frontend (Next.js/React).

## ✨ New Features

### Realtime Voice Chat (Immersive Mode)
- **Hands-free voice chat**: CPU-only ASR (faster-whisper, int8, `base` model default) with VAD silence-hangover segmentation and auto-send on pause.
- **Latency-tuned ASR**: ~1.49–1.69 s median end-to-end on CPU; simplified-Chinese + punctuation stabilized via `initial_prompt` (full measurements in `docs/benchmarks/latency-v0.1.3.md`).
- **Screen/camera capture**: frame capture and realtime subtitle overlay (`CameraPanel`, `SubtitleOverlay`, `ImmersiveChatWindow`).
- **GPU acceleration reserved**: TTS engine supports `--device cuda`; ASR GPU path reserved for future models.

### Local TTS Voice Replies (Genie-TTS)
- **Standalone Genie-TTS engine** (`scripts/genie_server.py`): HTTP service at `http://127.0.0.1:8050`, CPU by default, `--device cuda` for NVIDIA GPU; Django never loads it in-process.
- **ONNX voice conversion**: `/convert_to_onnx` and `/convert_status` endpoints for model conversion; `scripts/patch_genie_tonesandhi.py` fixes the tonesandhi package on Windows.
- **Per-character voice model settings**: the single place to configure TTS per character, with an engine-aware voice-model form that adapts to the selected engine's parameters.
- **Per-user engine settings + shared voice library**: users configure their TTS engine preference (genie, api_v2, indextts reserved); the voice library aggregates available voices with emotion groups.
- **Emotion groups**: per-emotion reference audio, scoped by synthesis language, moved into voice library entries.
- **Voice settings panel**: `TtsSettingsPanel` with audio/model directory path pickers, upload-convert flows, and engine-level configuration.

### Chat UX
- **Paragraph-split message bubbles**: long replies are split into paragraphs, each with its own speak and download buttons.
- **Segment audio prewarm + cache**: audio is prewarmed after reply generation and played from cache on speaker click, avoiding repeated synthesis.
- **Session message cache** (sessionStorage): switching characters shows history instantly without a loading flash.
- **Loading placeholder**: replaces the scene-card flash while history loads; history pinned to bottom on open.
- **Turn minimap + model switcher**: left-side turn minimap and main-model switcher; group context ring and model picker beside the send button.
- **Reply-length control**: per-character and per-message reply-length limits.

### Memory / Soul Panel
- **SoulPanel rework**: lazy, searchable memory tree replaces the flat list; shared `FileTree` component.
- **Folder-grouped uploads**: reference file uploads preserve folder groups for memory browsing.
- **Offset-aware pagination**: `GET /api/soul/files/` supports `offset` and `limit` for paginated reads; knowledge-asset listing endpoint.

### Character Management
- **Cascade delete**: deleting a character also removes its chat history and associated files, with cleanup confirmation.
- **Upload progress bar**: file count and progress shown during upload & AI analysis.
- **Voice library picker**: characters pick their TTS voice from the shared voice library instead of manual configuration.

## 🐛 Bug Fixes
- Removed the "open flash" entirely — loading placeholder instead of scene card; `dispatch` moved outside setState updater to prevent stale state.
- Repeat character click no longer wipes the session; history pinned to bottom on open.
- TTS playback reliability: serialized synthesis calls to prevent genie audio cross-contamination; genie `/stop` endpoint called before each synthesis to clear player state; emoji and non-language symbols stripped before synthesis.
- Gallery: expand chevron added to detail sections, hidden when sections are empty.
